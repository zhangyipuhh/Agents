# 快速入门

本章节介绍系统的核心功能与基本使用流程，帮助新用户快速上手。

## 登录系统

在浏览器中访问系统地址（如 `https://your-domain/`），进入登录页面。输入用户名、密码与验证码即可登录。

> 系统支持**双因素认证（TOTP）**，如您已启用 MFA，登录后会要求输入 6 位动态验证码。

## 主界面导览

登录成功后进入主界面，主要分为三个区域：

- **左侧栏**：会话历史、项目列表、用户菜单
- **中部对话区**：与智能体对话的主交互区
- **顶部输入区**：消息编辑、文件附件、斜杠命令等

### 切换智能体

系统支持多种智能体（Agent），不同智能体拥有不同的能力与工具集。可在顶部输入区上方的智能体切换器中选择。

## 发起对话

在输入框中输入您的问题，按 `Enter` 发送，`Shift+Enter` 换行。系统支持以下增强特性：

- **多轮对话**：上下文自动延续，支持「追问」「澄清」
- **文件附件**：点击附件图标上传文档、图片、表格等
- **斜杠命令**：输入 `/` 触发命令面板（如 `/clear`、`/help`）

## 知识库

系统提供独立的知识库模块，支持上传与管理个人或团队文档。

1. 点击左侧菜单的「知识库」按钮（或顶部「知识库」入口）
2. 上传文档后即可在与智能体对话时引用
3. 支持 PDF、Word、Excel、TXT 等格式

## 智能运维中心

面向运维人员的工作台，提供：

- **服务器管理**：纳管 SSH 服务器，支持手动 / 定时巡检
- **巡检脚本库**：可视化编辑巡检脚本，复用脚本模板
- **采集记录**：查看历史巡检结果、智能检测分析

详细说明见「[智能运维中心](/help/features/ops-console)」章节。

## 退出登录

点击左下角头像，弹出菜单中选择「退出登录」即可。
