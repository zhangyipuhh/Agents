# 知识库

知识库模块提供文档上传、检索与对话能力，支持个人知识库与团队共享知识库。

## 功能概览

知识库支持以下核心能力：

1. **文档上传**：支持 PDF、Word、Excel、TXT、Markdown 等格式
2. **自动分块**：上传后自动按段落 / 章节切分，支持自定义分块大小
4. **对话检索**：智能体会自动从知识库中检索相关内容作为回答依据

## 上传文档

点击「上传文件」按钮，选择本地文件即可。系统支持：

- 单文件最大 50 MB
- 批量上传（一次最多 20 个文件）
- 拖拽上传

## 文档解析

上传的文档会进入解析队列，系统会：

1. 提取文档文本（OCR 处理图片型 PDF）
2. 按段落 / 章节切分为 chunks
3. 生成向量索引用于语义检索

## 知识库对话

在主对话区，智能体会自动识别用户问题是否与知识库相关：

- 如相关：自动检索 top-k chunks 作为上下文注入提示词
- 如不相关：直接调用通用对话能力

## 文件夹管理

支持多级文件夹组织文档：

- 创建 / 重命名 / 移动文件夹
- 按文件夹授权（仅管理员可配置 ACL）
- 批量操作（删除、移动、导出）

## 索引重建

如检索效果不佳，管理员可在「知识库管理」中触发索引重建：

1. 删除现有索引
2. 重新解析所有文档
3. 重新生成向量索引

索引重建期间知识库对话能力可能受影响，建议在低峰期操作。
